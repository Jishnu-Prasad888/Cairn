# Memories and Markdown

Not yet implemented (Phase 8). Requirement summary.

## Memory objects

Memories are long-form Markdown documents — thoughts, journal entries, travel
logs, essays. There is no artificial short-content limit. Memories can link to
photos, videos, files, other memories, albums, people, and tags.

## Editor

Obsidian-inspired experience:

- editing with live preview and split view
- autosave with explicit save states
- version history per memory

## Internal references

Memories may reference other Cairn objects with wiki-style links. Users never
type IDs by hand; the editor provides a search/picker.

See [markdown.md](markdown.md) for the complete syntax.
